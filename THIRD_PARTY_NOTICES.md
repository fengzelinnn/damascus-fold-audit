# Third-party provenance

The reference implementation is newly written for this project. No code from the legacy Damascus or BPoSt repositories is included. Those repositories were read only as audit evidence; their local snapshots are excluded from publication and packages.

Plotting uses the exact Python dependency versions listed in `requirements-plot.lock`. Copies of the installed distributions' license/notice files and their metadata are preserved in `licenses/dependencies/`. They apply to those dependencies and are not a license for the new project code. The release does not vendor the dependency implementations.

The project's own distribution license has not been selected by the owner. Public visibility alone is not a grant of an open-source license. Baseline software license observations are documented separately in `docs/baselines.md`; no baseline implementation is included.

Raw manuscript files, legacy source snapshots, machine inventories and measurement logs are not part of the public source release.
